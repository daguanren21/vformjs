# 实践：需求来了怎么带 AI

本目录讲的是 **工作方法**，不是某个仓库的功能 demo。

## 从这里开始

**[先看这个.md](./先看这个.md)**  

内容：产品丢来一句话需求后，按顺序：

1. 进队  
2. 问清楚 / 标未知  
3. 对错表  
4. 人批规格  
5. 拆任务  
6. AI 实现  
7. 独立验收  
8. 人批提交  

并附上可直接复制给 AI 的口令。
